# Terraform Modules (`infrastructure/terraform/`)

Infrastructure as Code (IaC) modules and environment workspaces for provisioning cloud resources dedicated to the OICUNT AI Platform.

---

## Managed Resources

- Dedicated AI VPC subnets and private peering with upstream platform networks.
- Cloud IAM roles and fine-grained access policies for AI workloads.
- Specialized GPU node pools and autoscaling groups.
- Managed vector database clusters and document staging storage buckets.
- Cloud KMS keys and secret stores for AI provider credentials.
